
# 🔐 Password Generator

A responsive password generator built using HTML, CSS, and JavaScript.


## Live Demo 🚀

https://prathampatil2002.github.io/Password-Generator/


## 🚀 Features

- Generate random passwords
- Adjustable password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Copy password to clipboard
- Responsive design
- Client-side password generation

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Clipboard API
