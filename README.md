
# 🔐 Password Generator

A responsive password generator built using HTML, CSS, and JavaScript.

## 🚀 Features

- Generate random passwords
- Adjustable password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Copy password to clipboard
- Responsive design
- Client-side password generation

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Clipboard API

## 📂 Project Structure

password-generator/
│
├── index.html
├── style.css
├── script.js
└── README.md

## ▶️ How to Run

1. Clone the repository
2. Open the project folder
3. Open `index.html` in your browser
